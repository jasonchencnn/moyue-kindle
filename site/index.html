它是什么

What it is

直接跑在 Kindle 硬件上的原生阅读器。不是浏览器套壳，不经过安卓，不依赖亚马逊服务。

A native reader running directly on Kindle hardware. No browser shell, no Android, no Amazon services.

原生性能

Native performance

Rust 编写，单个静态 ARM 可执行文件。启动约 4 秒，翻页提交 4–6 ms。

Written in Rust, shipped as one static ARM binary. ~4 s launch, 4–6 ms page-turn submit.

KOReader 同源排版

crengine layout

EPUB / TXT 使用 KOReader 的 crengine 引擎，中文排版成熟；改字号先排当前页，后台补全书。

EPUB/TXT via KOReader's crengine, with mature CJK typography and local reflow on font changes.

Readest 同步

Readest sync

同一个 Readest 账号：阅读进度、高亮笔记、云端书库。进度用 XPointer，与 KOReader 互通。

Same Readest account: progress, highlights, notes and cloud library. XPointer positions, KOReader compatible.

为墨水屏设计

Made for e-ink

无动画、高对比、局部刷新；实体翻页键和重力旋转都可用；前光跟随原系统。

No animations, high contrast, partial refresh; page buttons and rotation; stock frontlight control.

中文优先

Chinese-first

简体中文界面与内嵌中文字体，支持 GBK/GB18030 TXT、拼音排序与拼音输入。

Simplified Chinese UI, bundled CJK font, GBK/GB18030 TXT, pinyin sorting and input.

开源、可自建

Open source

AGPL-3.0-or-later；同步协议兼容 Readest，服务端地址可配置；代码与构建脚本全部开放。

AGPL-3.0-or-later; compatible sync protocol with configurable endpoints; all code and build scripts public.

安装

Install

只支持 Kindle Oasis 2（第 9 代，2017）+ 固件 5.16.x + 已越狱 + KUAL。安装包由源码构建，详见仓库文档。

Kindle Oasis 2 (9th gen, 2017), firmware 5.16.x, jailbroken with KUAL. Build the package from source.

  1. 备份 Kindle 上的 .aristotle/、documents/ 与 My Clippings.txt。
  2. 按 BUILD.md 构建设备包，得到 aristotle/ 与 extensions/。
  3. 把两个文件夹复制到 Kindle USB 盘根目录，合并覆盖同名文件。
  4. 安全弹出，打开 KUAL → 墨阅 → 启动墨阅。
  5. 打开一本书，检查正文、翻页键与触摸；需要时在设置里登录 Readest 账号。
  1. Back up .aristotle/, documents/ and My Clippings.txt on the Kindle.
  2. Build the device bundle as described in BUILD.md.
  3. Copy aristotle/ and extensions/ to the Kindle's USB root.
  4. Eject safely, then start it from KUAL → 墨阅 → 启动墨阅.
  5. Open a book and check reading, page buttons and touch; sign in to Readest in Settings if needed.

预览版没有验证过整机救砖路径，请先备份。不要写入启动分区、bootloader 或系统分区；不要在别人的设备上试未经确认的操作。完整步骤、风险与卸载恢复见 docs/INSTALL.md。

This preview has no verified full-recovery path. Back up first; never write to boot partitions, the bootloader or the system partition. Full steps and risks: docs/INSTALL.md.

Sync with phone and desktop

实现 Readest 的同步协议，用同一个账号，无需另建服务。

Implements the Readest sync protocol; one account, no extra server needed.

进度

Progress

XPointer 存档，与 KOReader 互通；拉到更新的进度会先提示再跳转。

Stored as XPointer, KOReader compatible; newer remote positions prompt before jumping.

高亮与笔记

Highlights & notes

按 id 合并、墓碑删除；拉取与推送都支持手动与自动。

Merged by id with tombstones; manual and automatic pull/push.

云端书库

Cloud library

列出 Readest 云端书籍，流式下载、哈希校验后入库。

List cloud books, download with hash verification.

登录

Sign-in

邮箱密码登录，默认走官方认证中转；密码不落日志。

Email/password via the official auth relay; passwords never logged.

已知限制：TXT 进度不跨端；同一本书 book_hash 不同时按百分比同步；超长文本节点与 <pre> 首行定位可能偏一页。详见 docs/SYNC.md。

Known limits: TXT progress is local-only; different book_hash syncs by percentage; very long text nodes / <pre> first lines may land a page off. See docs/SYNC.md.

从源码构建

Build from source

需要 Rust、Zig 交叉工具链与 CMake。首次构建会下载并编译第三方 C/C++ 库，约 10–20 分钟。

Requires Rust, Zig cross toolchain and CMake. The first build downloads and compiles the C/C++ stack (10–20 min).

git clone --recursive https://github.com/jasonchencnn/moyue-kindle.git
cd moyue-kindle
./scripts/check.sh                    # pure-Rust checks (fmt / clippy / tests)

. aristotle/tools/env.sh              # ARISTOTLE_CACHE + build cache
export CARGO_TARGET_DIR="$ARISTOTLE_CACHE/target"
cd aristotle
tools/fetch-tools.sh                  # pinned Zig toolchain
tools/build-plato.sh                  # Plato C libraries
tools/build-render.sh device          # static ARM app + device bundle
tools/package.sh                      # zip with aristotle/ + extensions/

状态与限制

Status and limitations

当前是 预览版 / 实验性。已真机验证：排版引擎、翻页、选词高亮、目录链接、休眠唤醒、前光、Wi-Fi 传书、中文界面、局部重排。仍在验收：扫描导入流程、手动同步与自动推送、长时阅读内存、真实账号跨端同步。

Currently a preview / experimental build. Verified on hardware: layout engine, page turns, selection and highlights, TOC/links, sleep and wake, frontlight, Wi-Fi transfer, Chinese UI, local reflow. Still under acceptance: scan/import flow, manual sync and auto-push, long-session memory, cross-device sync with a real account.

已知问题：部分 SVG 封面显示为黑框白页、英文两端对齐词距异常、大书缓存超限、快速连点翻页合并、阅读页不能给划线加笔记、PDF 封面仅支持首图。完整列表见 KNOWN-ISSUES。

Known issues: SVG-only covers render blank, English justification spacing, large-book cache overflow, rapid taps coalesce, no notes on existing highlights, PDF cover limited to the first page image. Full list: KNOWN-ISSUES.
