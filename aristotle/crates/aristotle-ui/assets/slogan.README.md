# slogan.mask

The status bar slogan 「墨阅——用心阅读」, 394 x 48 px, as an 8-bit coverage
mask (one byte per pixel, row by row, 255 = ink). `slogan.png` is the same
picture for viewing.

The characters are rendered from Ma Shan Zheng (MaShanZheng-Regular.ttf,
google/fonts `ofl/mashanzheng`), licensed under the SIL Open Font License 1.1
(`licenses/MaShanZheng-OFL.txt`). Only the rendered picture ships; the font
file does not. The dash is drawn as a single rounded bar, not the font's glyph.
