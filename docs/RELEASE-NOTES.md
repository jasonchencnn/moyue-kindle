# 版本记录

## 0.3.3 源码快照（2026-11-23）

- **坚果云 WebDAV 与三渠道同步**：新增坚果云 WebDAV 协议栈、登录配置页、云书架与双向同步管线（支持进度与标注/墓碑合并、按书隔离同步代际与失败自动入队重试），并与 Readest、微信读书统一接入三渠道云同步界面。
- **中文精排引擎全面升级**：开启 LunaSVG（内联 SVG）、libwebp、内置 GIF 与 MathML；新增多看（`duokan-page-fullscreen` / `duokan-page-fitwindow`）、微信读书、现代 EPUB3 精排 CSS 与图片脚注热区弹窗识别；启用 `cjk-tailored` 中文字格对齐、`zh-CN` 标点挤压与真实屏幕 DPI 透传，精排模式下保持原书版式无侵入。
- **微信读书渠道**：支持网页登录、云端书架下载与位置恢复、进度读写仲裁、阅读时长上报与划线/想法只读同步。
- **阅读器体验增强**：新增纯 Rust 古籍竖排（`vertical-rl`）引擎、整句翻译弹窗（Edge / MyMemory 回退）、可折叠二级目录、应用内 OTA 实时进度更新、字重/精细排版设置及 6 寸屏（Kindle 10 等）多尺寸布局适配。

## 0.3.1 预览版（2026-11-15）

支持 Kindle Oasis 2 / 5.16.x。首次从 0.3.0 升级需要 USB 安装，后续可在 KUAL 使用“检查更新”。安装包、OTA 包、完整对应源码和 SHA256SUMS 随 GitHub Release 提供。

- KUAL 增加 OTA 更新、诊断日志采集与需有效凭据的上传入口。
- TXT 加入预热调度与转换进度，改进中文/英文正则分章，并兼容旧转换器保存的进度和标注。
- TXT 章节边界与 EPUB 实际目录目标从新页开始。
- 排版设置增加关闭、实线、点线三种逐行辅助线，支持持久化和日夜模式。
- 引擎可在运行时调整页面尺寸并重新排版，作为后续横竖屏支持的基础。
- 启动时支持正拿、倒拿的触摸和实体键映射。运行中自动旋转、重力开关和手动四向选择仍待实现。

根工作区与主机 Aristotle 的 fmt、clippy 和测试通过，引擎、渲染器与设备构建检查已通过。已有 ARM 全量测试记录为 211 通过、1 个既有休眠截图失败、3 忽略。EPUB 白屏问题仍待故障日志定位，真实账号跨端同步和设备交互回归待验收。

本版同时包含此前工作区的以下改动

- **扫描结果审核后再导入**：扫描只产生候选列表，逐本勾选后确认，才把书导入书库；可同时选择多个扫描目录，支持全盘扫描与目录黑名单，默认全部不勾选、跨页保留勾选状态。
- **导入即迁移**：确认后把选中的书移动到可配置的实体书库目录（默认 `documents/墨阅书库`）；先复制并校验目标文件、索引持久化成功后才删除原文件；重名不覆盖，取消/失败保留原文件。
- **阅读中管理**：阅读菜单可直接添加字体；前光支持 0–24 档；点击屏幕上下区域唤出菜单。
- **同步增强**：阅读页手动拉取/推送当前书；自动推送开关持久化；修复设置页手动同步的网络错误，错误分类更明确。
- **性能**：限制字形缓存与封面缩略图缓存，降低长时间阅读的内存增长。

## 0.3.0 预览版（2026-11）

首个面向 Kindle Oasis 2 的预览版。**不是稳定版**，安装前请读 [INSTALL.md](INSTALL.md) 与 [KNOWN-ISSUES.md](KNOWN-ISSUES.md)。

### 包含

- 中文界面（默认简体中文）+ English + polski。
- 本地书库：网格/列表、拼音排序、搜索、扫描本地书籍、长按菜单、滑动翻页。
- 本地阅读：EPUB / TXT（UTF-8、GBK、GB18030）/ PDF / CBZ，按文件情况支持无 DRM 的 MOBI / AZW3；EPUB 与 TXT 用 crengine 排版，支持局部重排。
- 阅读交互：选词、划线、笔记、链接脚注、目录、实体翻页键、启动时正拿/倒拿适配、夜间模式、前光跟随原系统、休眠与唤醒。
- 字体：内置思源黑体（Noto Sans SC）作为中文回退、Literata 作为西文正文；可通过 Wi-Fi 或 USB 放入 TTF/OTF 使用自定义字体。
- 排版：字号、行距、页边距、首行缩进、段间距。
- 首页、书库、我的、设置、阅读统计、阅读日历、单书统计、名言库、状态栏标语、休眠屏书摘。
- 高亮与笔记写入 `My Clippings`，并按书导出 Markdown。
- Wi-Fi 传书；我的划线与笔记浏览；Readest 账号登录、进度/笔记同步、云端书库下载。
- 封面优先使用书自带封面，没有才生成默认封面。
- KUAL 启动约 4 秒；连点只启动一个实例；运行期间不再让原厂写诊断日志包。
- 发布包内含许可证、`SOURCE.txt` 与对应源码包；不含亚马逊固件、波形文件、账号或设备序列号。

### 不包含

- 云同步统计、云端上传、设备配对、CFI 转换、夜间压暗前光、竖排、年度报告；
- 书内搜索、词典内置、翻页动画、标点挤压、繁简转换；
- 书库长按"移到文件夹"（入口已隐藏）。

### 对应源码

AGPL-3.0-or-later 要求分发二进制时提供对应源码。发布包中的 `SOURCE.txt` 标明版本与提交；源码即本仓库对应提交，第三方源码包（Plato、crengine 等）随发布包提供，清单见 [THIRD_PARTY.md](../THIRD_PARTY.md)。
