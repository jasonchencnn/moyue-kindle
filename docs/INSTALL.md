# 墨阅预览版：安装、卸载与恢复

> 适用版本：墨阅预览版 0.3.1（Kindle Oasis 2）
>
> 从 [GitHub Releases](https://github.com/jasonchencnn/moyue-kindle/releases/tag/v0.3.1) 下载本版安装包和校验文件。源码构建见 [BUILD.md](BUILD.md)。
>
> 本文只写已经实现、能够按步骤复现的内容。这是预览版，不是稳定版；安装前请先读“风险”和“已知限制”。

## 1. 支持范围

| 项目 | 预览版要求 |
|---|---|
| 机型 | Kindle Oasis 2（第 9 代，2017 年，设备代号 KOA2） |
| 固件 | 5.16.x（开发机为 5.16.2.1.1） |
| 前置条件 | 已越狱，KUAL 已安装并能正常启动 |
| 安装方式 | 解压发布 zip 到 Kindle 的 USB 盘根目录，从 KUAL 手动启动 |

**不支持**：Paperwhite 4、Paperwhite 3/5、Kindle Touch、Scribe 及其他机型；其他固件版本。设备的启动守卫会拒绝不匹配的机型和固件，并在屏幕上说明原因。除非你明确知道风险并自行设置 `ARISTOTLE_FORCE=1`，否则不要绕过守卫。

Paperwhite 4 的代码仍在仓库里，但本预览版没有在 PW4 上验证，也不随本次发布提供安装支持。

## 2. 风险

- 这是预览版。界面、阅读、休眠和恢复路径都还有未在真机上验证的部分，可能崩溃、卡死或显示异常。
- 本项目没有验证过任何一台设备的“整机救砖”路径。不要写入启动分区、bootloader、IDME、diags、`/mnt/wfm` 或 `/var/local` 之外的系统文件。
- 自启动（开机直接进入墨阅）默认不开。预览版建议只在 KUAL 里手动启动；自启动需要额外安装 agent，它会往根文件系统写入 3 个 Upstart 服务。没有验证过的恢复把握时，不要开自启动。
- 安装前先备份 `.aristotle/`、`documents/`、`aristotle-notes/` 和你的字体/词典目录。`.aristotle/` 里是阅读进度、偏好和索引；删掉它不能靠重新扫描书籍恢复。
- 墨阅只打开无 DRM 的书，不包含越狱、破解或去 DRM 代码，也不包含任何亚马逊固件或云端调用。

## 3. 准备

1. 一台已越狱并装好 KUAL 的 Oasis 2。
2. 一台电脑和 USB 数据线。
3. 本次发布的以下文件（来自同一个发布页）：
   - `moyue-preview-0.3.1.zip`
   - `moyue-preview-0.3.1-source.tar.gz`（源码包；日常安装不需要）
   - `SHA256SUMS`
4. 如果设备上装过旧版 Aristotle/墨阅，先按“更新”一节的顺序备份。

## 4. 校验发布包

在下载目录里校验 zip。macOS 或 Linux 都可以：

```sh
shasum -a 256 -c SHA256SUMS --ignore-missing
```

或者：

```sh
sha256sum --check --ignore-missing SHA256SUMS
```

zip 那一行必须显示 `OK`。校验值不一致就不要安装，重新下载。

## 5. 安装

1. 如果墨阅或旧版 Aristotle 正在运行，先退回原系统：
   - 在阅读页长按“书库”标题约 1 秒退出；或
   - 在设置里选择“返回 Kindle 系统”；或
   - 在 KUAL 里选择“墨阅 > 返回 Kindle 系统”。
2. 用 USB 线连接 Kindle，让电脑能看到 Kindle 的磁盘。
3. 把 `moyue-preview-0.3.1.zip` **解压到 Kindle 磁盘根目录**，和 `documents/` 同级。不要只把 zip 放进去。
4. 解压后根目录应出现：
   - `aristotle/`：程序和随包许可证、`SOURCE.txt`
   - `extensions/aristotle/`：KUAL 菜单
5. 等待复制完成，弹出磁盘后再拔线。
6. 在 Kindle 上打开 **KUAL > 墨阅 > 启动墨阅**。首次启动会比之后慢。

安装不会动你的书、`.aristotle/` 阅读数据或 `documents/`。

## 6. 第一次阅读

1. 把 EPUB、TXT 或无 DRM 的 MOBI/AZW3/PDF 放进 `documents/`。
2. 打开墨阅，进入书库；没有看到书时用书库里的“扫描”入口重新扫描。
3. TXT 支持 UTF-8 和 GBK/GB18030；EPUB 用 crengine 排版。
4. 阅读页点顶部打开菜单；Oasis 2 的实体翻页键可用。
5. 退出：长按“书库”标题约 1 秒，或从设置选择“返回 Kindle 系统”。

### 6.1 字体（F4）

- 内置中文字体是**思源黑体（Noto Sans SC）**；正文西文用 Literata。
- **不内置**宋体和霞鹜文楷。需要这两种字体时请自行安装。
- 安装字体：用 **Wi-Fi 传书**上传，或连接 USB 把 TTF/OTF 文件放进 Kindle 根目录的 `fonts/`。整套字族最好把常规、斜体、粗体、粗斜体放在一起。
- 排版面板只显示**已经安装**的字体；没有放进去的字体不会出现在选项里。

## 7. 更新到新预览版

0.3.0 首次升级到 0.3.1 时请按以下 USB 步骤安装。0.3.1 起，后续版本可从 **KUAL > 墨阅 > 检查更新** 安装，更新器会校验版本、大小和 SHA-256，并保留中断恢复入口。

1. 先备份：退出墨阅，连接 USB，复制 `.aristotle/`、`documents/`、`aristotle-notes/`（如有）和 `fonts/`、`dictionaries/` 到电脑。
2. 保持墨阅停止，重新连接 USB。
3. 把新 zip 解压到磁盘根目录，覆盖 `aristotle/` 和 `extensions/aristotle/`。**保留** `.aristotle/` 和书。
4. 弹出磁盘，从 KUAL 启动。
5. 打开一本最近读过的书，确认进度和高亮还在。

如果开了自启动，更新后需要在 KUAL 里再执行一次“开机启动墨阅：开”，刷新内部副本。旧版和新版可能读不了对方写的数据；升级前保留与旧版配套的备份。

## 8. 卸载

卸载不会删除你的书和 `My Clippings.txt`。

1. 退出墨阅，回到原系统。
2. 如果装过 agent，先在 KUAL 选择 **墨阅 > 完全移除 agent（服务、状态、SSH 密钥）**。这会删除 3 个 Upstart 服务、内部程序副本、更新拦截和 SSH 密钥。
3. 连接 USB，删除磁盘根目录下的：
   - `aristotle/`
   - `.aristotle/`（会删除阅读进度、偏好和索引；需要保留就先备份）
   - `extensions/aristotle/`
   - 如果存在：`extensions/aristotle-probe/` 或更早的 `extensions/aristotle-usbnet/`
4. 弹出磁盘并拔线。

## 9. 出问题时怎么退回原系统

### 9.1 墨阅还在运行，但界面卡住

- 长按“书库”标题约 1 秒；或
- 用 KUAL 选择 **墨阅 > 返回 Kindle 系统**；或
- 如果开了自启动且无法操作，先关机重启，然后在 USB 盘根目录创建空文件 `aristotle-disable`，再重启。这个文件会阻止 agent 和开机自启动的墨阅启动，原系统会正常起来。处理完删除它即可恢复。

### 9.2 墨阅能退出，但 KUAL 菜单也异常

1. 用 USB 连接，确认能进入 U 盘模式。如果 agent 把 USB 保持在网络模式，先在 KUAL 选择 **墨阅 > USB 磁盘模式 10 分钟**。
2. 在电脑上把 `aristotle/` 和 `extensions/aristotle/` 移走或删除。
3. 弹出磁盘，重启 Kindle。原系统应当正常启动。

### 9.3 有 KUAL，但自启动的墨阅起不来

先在 USB 盘根目录放空文件 `aristotle-disable`，重启进入原系统；再从 KUAL 关闭自启动或重新安装。

### 9.4 没有 SSH，也没有可用的 KUAL

越狱环境会在原系统启动后运行 `/mnt/us/emergency.sh`（以 root 身份）。把要执行的修复脚本放到这个路径，重启，等原系统起来后再删除脚本。例如：

```sh
sh /mnt/us/extensions/aristotle/agent/uninstall.sh
```

这条路径在开发机的 Paperwhite 4 上验证过；**没有在 Oasis 2 和本预览版上验证**。它要求原系统能够启动，并且重启时 `/mnt/us` 已挂载。

## 10. 固件升级前

- 先卸载 agent：**KUAL > 墨阅 > 完全移除 agent**。
- 保留磁盘根目录的 `update.bin.tmp.partial/` 文件夹，不要删除。
- 固件升级会清掉或改变系统服务；升级后重新按本文安装，不要假设旧版还能启动。

## 11. 已知限制

本预览版不包含或尚未完成：

- 云端统计同步；Readest 登录、进度/笔记同步与云端下书已经实现，真实账号跨端验收仍在进行；
- 书库长按“移到文件夹”；
- 设置里的字体、日期时间、预览项（会进入“即将推出”页）；
- 书内全文搜索（现有搜索只查书库，不搜正文）；
- 每日目标不能修改，固定 30 分钟，只在“我的”里显示进度；
- 运行中自动旋转、重力开关和手动四向选择。

本版不提供翻页动画、标点挤压、繁简转换。

此外：

- 词典查词只支持用户自备的 StarDict 词典；应用不内置词典，没有词典时查词只显示提示，Kindle 商店词典不支持；
- 首行缩进、段间距、休眠屏书摘、Wi-Fi 传书已实现，真机回归仍在进行；本版保留这些功能，没有回退；
- 时钟样式在设置里循环切换 4 种样式，没有独立选择页；重启后是否保留和实际观感待真机回归；
- 约 30 个界面任务只在主机出图验证过，尚未逐项上真机；
- 连续阅读、休眠唤醒多次、大书、断电后的进度恢复仍需真机回归；
- 电池续航没有验证数据；
- Paperwhite 4 不在本预览版支持范围。

完整的功能范围和已知问题见[版本记录](RELEASE-NOTES.md)与[已知问题](KNOWN-ISSUES.md)。

## 12. 反馈

反馈时请附上：

- 机型、固件版本、墨阅版本（设置 > 关于）；
- 复现步骤和出现频率；
- 日志：KUAL 启动的日志在 `/mnt/us/.aristotle/app.log`，上一次运行在 `app.log.1`；
- 如果是启动或 agent 问题，再附 `/var/local/aristotle/log` 和 `/mnt/us/aristotle-agent.log`（如有）。

0.3.1 可在 **KUAL > 墨阅 > 诊断日志 > 采集日志** 生成诊断报告，采集后通过 USB 取出报告反馈。上传功能需要另行配置有效支持凭据，公开安装包不含凭据。

不要提交账号密码、设备序列号或版权书籍。
