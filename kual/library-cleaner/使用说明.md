# 墨阅书库清理

适用于全局扫描后书库出现大量误导入内容的情况。脚本将整个书库列表清空，供重新选择书籍导入。请先安装带有“扫描后勾选确认导入”功能的新版墨阅，旧版的自动扫描可能再次填满书库。

## 安装和运行

1. 将 ZIP 解压，把其中的 `moyue-library-cleaner` 文件夹复制到 Kindle 磁盘的 `extensions` 目录。
2. 安全弹出 Kindle。退出墨阅，回到 Kindle 系统界面。
3. 打开 KUAL，依次点击“墨阅书库清理” → “备份并清空书库列表” → “确认清空（进度与笔记归档到备份）”。
4. 屏幕显示 `Library cleared. Backup: ...` 即完成。重新启动墨阅，扫描后勾选需要的书籍并确认导入。

屏幕显示 `exit Moyue to Kindle first` 时，先退出墨阅，再执行清理。出现其他 `Cleanup failed` 提示时，请拍照反馈完整提示。

## 数据与备份

清理目标为默认书库 `/mnt/us/.aristotle/library.json` 及其日常回退文件 `library.json.bak`。使用自定义 `--library` 路径的安装需要单独适配。

原索引会完整备份至 Kindle 磁盘根目录的 `.moyue-library-backup-日期-时间-编号` 文件夹。每次运行生成独立备份。请保存第一次清理的备份。

阅读进度、笔记、书签与逐书设置保存在该备份里。清理后的书库重新导入时会建立新记录。如需恢复原阅读状态，可按下节恢复整个旧书库。

## 恢复旧书库

退出墨阅，通过 USB 连接电脑，在电脑开启“显示隐藏文件”。从第一次清理的备份文件夹中取出 `library.json`，复制两份到 Kindle 磁盘的 `.aristotle` 文件夹，分别命名为 `library.json` 和 `library.json.bak`，覆盖当前文件。如果备份中只有 `library.json.bak`，使用它作为这两份文件的内容。安全弹出后启动墨阅，即可恢复清理前的列表与阅读状态。

恢复整个旧书库也会恢复当时误导入的列表。重新导入后产生的新阅读状态应另行备份。

## 中断处理

脚本遇到备份或写入失败会退出，原索引归档保存在上述备份目录。清理过程中请保持设备供电。

如果设备突然重启后出现 `cleanup lock exists`，退出墨阅，在电脑确认备份文件已保存后，删除 `.aristotle/.library-cleaner-lock` 文件夹，再运行清理。

本工具已通过本机模拟测试，Kindle 真机菜单显示、清空及恢复流程待验证。
