# 墨阅 SSH（PW4 独立 KUAL 扩展）

只支持 Kindle Paperwhite 4（设备代码 `0PP`）固件 `5.18.1.1.1`。安装前把**公钥**写入本目录的 `authorized_keys`（每行一个，文件不入库），私钥不要放到 Kindle。

## 安装

1. 将 `ssh/` 整个目录放到 `/mnt/us/extensions/`，或按现有 KUAL 打包方式安装。
2. 写入公钥：`/mnt/us/extensions/ssh/authorized_keys`。
3. KUAL → 墨阅 SSH → 安装并启动。

安装会复制 `/mnt/us/koreader/dropbear` 到 `/var/local/moyue-ssh/`，并写入唯一的 upstart 文件 `/etc/upstart/moyue-ssh.conf`。写入根分区前自动 `mntroot rw`，结束（含失败）恢复 `mntroot ro`。

## 行为

- 服务：`dropbear -F -E -R -s -p 22`，只接受公钥，监听 22。
- 防火墙：只给 `wlan0` 增加 TCP 22 的 `NEW,ESTABLISHED` INPUT 放行；停止时删除同一条规则，不修改默认策略，不开放蜂窝接口。
- 开机：安装后默认启用。禁用会停止并移除开机标记，KUAL 的“启动”仍可临时运行。
- 端口：启动前检查 22 是否已被其他进程监听，被占用则拒绝，不停止别人的服务。
- 状态目录：`/var/local/moyue-ssh`，`root:root`、`000`，服务启动前校验属主/权限，先 `cd` 再用相对路径执行。

## 卸载

KUAL → 卸载服务：停止服务、删除 `/etc/upstart/moyue-ssh.conf`，保留 `/var/local/moyue-ssh` 以便重新安装恢复。不会动 KOReader 的 2222 服务或 `/etc/upstart/sshd.conf`。
